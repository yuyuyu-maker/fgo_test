Ours 的总目标不含 $\mathcal{L}_{\mathrm{rx0}}$ 与 EMA 端点。主实验是官方 Go2 MDP。IsaacLab 只留一条 FPO++ 先行记录。

Method

完整方法只使用：$\mathcal{L}_{\mathrm{FPO}}$、reward-aware 在线 Reflow、自适应积分预算、辅助零初值混合（$p_0=0.25$）、冻结 PPO 教师蒸馏。

Problem Formulation

条件流策略将观测 $o$ 映射为动作 $a\in\mathbb{R}^{d_a}$。速度场 $v_\theta(o,t,x)$；$t=1$ 噪声端，$t=0$ 动作端。

$$x_t = t\,x_0+(1-t)\,x_1,\qquad u^\star(x_0,x_1)=x_0-x_1.$$ $$a=\mathrm{ODE}_{v_\theta}^{(N)}(o,x_0),\quad N=64.$$

少步 $k\ll N$（尤其 $k=1$）下弯曲传输放大离散误差。本文在 FPO++ 上叠加在线 Reflow 与 PPO 动作蒸馏。

Overall Framework

$$\mathcal{L}_{\mathrm{FPO}}=\mathcal{L}_{\mathrm{surr}}+\lambda_V\mathcal{L}_V.$$

Ours：

$$\mathcal{L}=\mathcal{L}_{\mathrm{FPO}}+\lambda_r\mathcal{L}_{\mathrm{reflow}}+\lambda_a\mathcal{L}_{\mathrm{ada}}+\lambda_{\mathrm{KD}}\mathcal{L}_{\mathrm{KD}}.$$

默认 $\lambda_r=1$，$\lambda_a=0.1$，$\lambda_{\mathrm{KD}}=0.1$。不包含 $\mathcal{L}_{\mathrm{rx0}}$。

Online Reflow

端点由学生流积分（截断梯度），直线段上回归。Ours 用 advantage 加权 $w_i=\max(A_i-\tau,0)$，$\tau=0$，$n=4$。

$$\mathcal{L}_{\mathrm{reflow}}=\sum_{i,k}\tilde w_i\,\ell_{i,k},\qquad \ell_{i,k}=\|v_\theta(o_i,t^{i,k},x_t^{i,k})-u^{i,k}\|^2_{\mathrm{red}}.$$

Adaptive Compute and PPO KD

$$\mathcal{L}_{\mathrm{ada}}=\|a_{\hat k}-a_N\|^2+\alpha\mathbb{E}[L_{\mathrm{lat}}]-\beta\mathbb{E}[\mathrm{relu}(A)].$$ $$\mathcal{L}_{\mathrm{KD}}=\frac{1}{|K|}\sum_{k\in\{64,8,4\}}\|a^{(k)}-a_T\|^2.$$

$a_T=\mathrm{PPO}(o)$（stop-gradient）。辅助项以 $p_0=0.25$ 置零 $x_0$。

先行记录：IsaacLab 上的 FPO++

想法先在 IsaacLab Flat Go2 的 FPO++ 上跑通：baseline 1-step 掉 9.29，加上 reward-aware 后 1-step 与 64-step 持平。该栈没有官方观测/奖励对齐、没有 PPO 教师、也没有部署用域随机化与 HW 回放，真机侧缺动作先验和 1-step 导出，实际机器效果不好。主架构因此改为官方 Go2 MDP + RA-reflow + PPO 蒸馏。Spot 全表与 $\lambda_r$ 短消融不再进入正文。
