## 2. 新机器前置条件

1. **NVIDIA GPU** + 可用驱动（`nvidia-smi` 正常）。
2. 磁盘空间建议预留 **≥ 40G**（解压后代码 + 两套环境 + 临时空间）。
3. **conda / Isaac 二进制必须放在可执行的本地盘**  
   - 若 `/workspace` 是 bosfs / NFS 且带 `noexec`，不要把 conda 解到那里。  
   - Go2 环境推荐：`/tmp/isaaclab_conda` 或本机 NVMe。  
   - 机械臂环境推荐：`$HOME/miniconda3_fpo_manipulation`（与脚本默认一致）。
4. 代码布局建议对齐本机：

```text
/workspace/fgo_test/
  unitree_rl_lab/
  isaaclab_experiments/
  manipulation_experiments/
```

路径对齐后，现有 shell 脚本大多不用改。

### 4.7 Go2 概念注意（避免踩坑）

- 官方 Unitree Go2 MDP 是 **45-D** policy obs（无线速度）；旧 `go2_deploy` 是 **48-D**，ONNX / 权重不要混。
- 术语：**FPO++** = baseline（`reflow_enabled=False`）；`reflow` / `all_ideas` / `teacher_kd` 等是后续创新变体，不是 FPO++。
- headless 下偶发 Vulkan `ERROR_INCOMPATIBLE_DRIVER` 可忽略（与本机相同现象）。

## 5. 机械臂：解压与恢复

### 5.1 为什么原目录 ~212G，包只有 ~14G？

`manipulation_experiments/runs` 里每个成功 run 存了大量 `checkpoints/step_*` 中间权重（合计约 **201G**）。  
精简策略：

- 每个有结果的 run：**只保留 `checkpoints/best`**
- 打包时仍在训练的 2 个 run：**额外保留 `latest`**，便于 resume
- 无 checkpoint 的失败 / 空 eval run：只带少量元数据或跳过

### 5.2 拆开 ALL 包


### 5.4 恢复机械臂 conda 环境

**注意：** `fpo_manipulation_env.tar.gz` 打的是 **环境目录本身**：

```text
envs/fpo_manipulation/...
```

而 `manipulation_experiments/source_env.sh` 期望：

```text
$HOME/miniconda3_fpo_manipulation/          # conda base
$HOME/miniconda3_fpo_manipulation/envs/fpo_manipulation/
```

推荐两种接法：

**A. 已有任意 Miniconda / Mamba base（推荐）**

```bash
# 假设 base 在 $HOME/miniconda3_fpo_manipulation（没有就先装一个空 base，或改 source_env.sh）
mkdir -p $HOME/miniconda3_fpo_manipulation
tar -C $HOME/miniconda3_fpo_manipulation -xzf fpo_manipulation_env.tar.gz
# 得到 $HOME/miniconda3_fpo_manipulation/envs/fpo_manipulation
```

若你的 conda base 在别处（例如 `$HOME/miniconda3`）：

```bash
tar -C $HOME/miniconda3 -xzf fpo_manipulation_env.tar.gz
# 然后改 source_env.sh 里 CONDA_ROOT=$HOME/miniconda3
```

**B. 临时直接用环境里的 python（不经 conda activate）**

```bash
tar -C /opt -xzf fpo_manipulation_env.tar.gz
# /opt/envs/fpo_manipulation/bin/python ...
export PATH=/opt/envs/fpo_manipulation/bin:$PATH
```

正式训练仍建议走 `source_env.sh`，避免缺 `conda` hook / 库路径。

| 命令 | 作用 |

## 8. 故障排查

| 现象 | 处理 |
|------|------|
| `Permission denied` / 无法执行 conda 里的二进制 | 环境解到了 `noexec` 盘；换本地盘并改 `CONDA_ROOT` |
| `torch.cuda.is_available() == False` | 查驱动、`CUDA_VISIBLE_DEVICES`、GPU 是否被占满 |
| Isaac / Omni EULA | `source_env.sh` 已设 `OMNI_KIT_ACCEPT_EULA=YES` |
| Go2 部署行为异常 | 确认是 45-D 官方 MDP 权重，不要混旧 48-D `go2_deploy` ONNX |
| manip `source_env.sh` 找不到 conda | 确认 `$HOME/miniconda3_fpo_manipulation/bin/conda` 存在，且 `envs/fpo_manipulation` 已解压到位 |
| 磁盘不够 | 先删解压临时目录；不要解压机械臂全量 `step_*`（本包本就不含） |
